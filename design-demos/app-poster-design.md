# 小程序固定分享海报

用户本轮指定：“直接设计一张海报，后面直接复用吧，不需要每次生成了”，并提供固定小程序码，要求所有环境共用。沿 `direction-approved.md` 已确认的蓝白方向直接完成推荐方案。

## 最终设计与资源

- 成品：`images/app-share-poster.png`，900×1200，严格 3:4。
- 真实圆角 Logo、品牌名和两行大字“知识无界 / 挑战不停”；副文案为“用你的知识储备，刷新自己的纪录”。挑战、练习、错题分别展示产品用途。
- 用户提供的码原图为 `design-demos/app-share-code.jpg`，344×344，成品在 (492, 822) 以 1:1 完整绘制，不裁切、不覆盖、不重画。
- 所有环境直接展示同一张成品，不请求小程序码，不绘制 Canvas；保存时读取本地图片路径后调用既有相册保存流程。
- 题目海报继续按真实题号生成专属码并动态排版。

## 离线维护

`app-poster-render.js` 是离线设计源，`app-poster-preview.html` 加载真实 Logo 与用户码后绘制海报。通过本地 HTTP 服务预览，成品取 Canvas 的 PNG 导出。整个 `design-demos` 目录不进入小程序运行包。

布局已通过本机 Chrome 实际绘制并查看。完整测试、资源审计及编译记录见 `../docs/app-static-poster-2026-11-07.md`。微信实际扫码和相册权限交互仍以真机复验为准。
