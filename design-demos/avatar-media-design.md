# 默认头像与题图展示

- 默认头像：蓝白“知识探索者”，轻蓝圆形背景、圆眼镜、微笑与一点金色星光。不包含书本、文字。源文件 `vector-assets/default-avatar.svg`，通过 Chrome Canvas 导出 `images/default_avatar.png` 后用 oxipng 无损压缩。192 × 192，RGBA，透明圆角外区域，5608 字节。未改用户真实照片或头像引用。
- 答题、练习、Single 三页：显式 `question_image` 图片固定 200px 容器，`aspectFit` 保留整张图；视频固定 200px 容器，`object-fit="contain"`。题图点击预览和视频原播放属性保持。
- 海报：题干图片（含从 HTML 提取的图片）统一 756 × 360 画布像素浅底框，等比居中，无裁剪，不拉伸。小图仍保留原有最高放大两倍规则。选项图片仍按原比例展示；题干、选项文本和整张题目海报继续自适应高度。App 海报的 900 × 1200 规格和文案未改。
- 视频海报：原实现只有“本题含视频，扫码后查看完整视频”文字；现加蓝色播放标记和浅底提示卡。不会下载视频、抓取封面、自动截帧或把视频嵌入静态图。二维码仍绘制服务端原始图，扫码进入对应 Single 后播放原视频。题目 ID 和二维码请求、验证不变。

## 覆盖边界

页面的 HTML 内容原样传给微信 `rich-text`，并无自有 HTML 节点解析器。本次页面 200px 规则仅覆盖独立 `question_image`，不尝试修改 rich-text 中的内嵌 img，也不改变解析与渲染业务。海报已有独立的安全媒体提取，故 HTML 中的题干图片也受固定 360px 框约束。

预览页面：`avatar-media-preview.html`。截图：`avatar-media-preview.png`。Chrome 使用真实海报绘制函数和演示媒体生成截图；截图中的“预览码”是显式演示占位，未伪造真实二维码。已查看头像192/80/40px、横/竖图完整四角以及视频海报。页面原生布局与视频播放仍需微信开发者工具/真机验收。
