# 每轮题数扩展与切题滚动复位

每轮普通挑战可设置1–500题，未设置/非法偏好默认50题，已有合法个人偏好保留。首页和答题设置共用解析、保存与输入钳制方法，快捷项为10、20、50、100、150、200、300、500，两行四列；超出500的数字输入立即回写500，尚未确认不落盘。加号只在500禁用，步进仍保护1/500两端。帮助说明同步。每日练习100题目标与金币规则不变。

后端现有接口分批返回题目，客户端在开轮时快照题数并在到达上限时调用已有finish-challenge；没有后端100题硬上限，不改服务、数据库或批次协议。回归覆盖500题跨84批且恰好停止、新默认50与已有偏好保留、输入超限/非法、八档快捷、模板层加号边界。

挑战和练习切换题目时，在新题setData完成回调中调用零动画pageScrollTo(0)。用题号与视图序列防止旧回调影响新题，隐藏/卸载/离页/纠错/海报/订阅/其他modal时跳过。计时按原流程立即启动，不等回调；提交结果不会强行回顶。新增12项队列回调验证，Node仅证明调用契约，不等同真机滚动位置验收。

布局投影320×440、375×640两入口八档均四列两行、无横向溢出；短屏输入和确认按钮可见。Setting仅补短屏紧凑与非裁切主体，Home既有样式不变。本轮不提交生产答案、不发币或通知。最终完整测试与开发版上传见release-2026-11-01.md。
