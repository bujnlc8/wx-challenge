# 纠错键盘与练习进度抖动修复

用户报告纠错弹窗键盘弹起后验证码无法输入，并指出练习Tab的今日已练加载区域抖动。

复现：旧纠错模板在320×480/键盘200、375×603/键盘300、430×650/键盘320的源码布局投影中，验证码框均超出正文滚动裁切区，命中检测失败。验证码移到独立不压缩区域，随弹窗留在键盘上方，问题类型和备注继续内部滚动；textarea声明fixed，验证码输入增加光标间隔。三组相同条件验证码完整可见且命中检测通过。保留原输入、验证码token、题目/账号隔离、提交禁用与遮罩规则。

练习页之前每次onShow清空已加载数据，且loading与ready结构高度不同。现在同账号同北京时间日期保留真实进度并静默刷新；失败保留最后结果并提示重试，跨日、换账号、登录失效立即清理，晚返回响应继续隔离。今日已练的标题、进度条、状态区常驻占位，未加载不显示虚构0。

先观察2项新行为测试失败后修复。最终280项Node回归通过；320/375/430三种屏宽下loading/ready/error/logged-out/refresh-error共15组布局，卡片高度和规则卡位置一致、无横向溢出。验证码键盘投影3组，以及既有确认/纠错12组布局通过。官方WXML/WXS与WXSS编译通过，diff无空白错误。

浏览器投影只验证布局和点击命中，不等同iOS/Android实际软键盘输入验收；未向生产提交任何纠错或制造答题记录。上传状态见release-2026-11-01.md。
