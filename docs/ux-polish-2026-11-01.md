# 第二轮界面体验优化

本轮用户采纳六项建议，并追加全部业务弹窗和验证码样式统一、去掉练习底部操作区分隔线。

- 练习首页读取本人真实北京时间当日去重题数与实际奖励账本。加载/失败/未登录独立呈现，不用假数字；已到账来自服务端source5记录。
- 练习答完主按钮变为下一题，正确或错误都可继续；不重复提交，旧题导航保留。当前题用时以mm:ss/h:mm:ss固定格式显示，避免秒数位数推动顶栏。
- 每日挑战读取本人今日对共同题目的ACCEPTED记录，错题也算完成。已完成显示完成态和再答一次；仍开同一题，不承诺不存在的历史题目快照回顾。紧凑首卡使热力图更容易看到。
- 百科币流水为来源与时间两行，右侧突出真实金额；设置页去掉重复大标题/宣传句，直接展示设置项。
- 全部既有业务弹层统一24/26圆角、18标题、轻量关闭触达、48主次按钮、短内容自然高和长正文内滚。保留锁、全屏点击屏障、确认回调、声音与异步隔离。确认文案仅展示逐行去末尾句号，原content不改。
- 纠错面板真实checkbox卡片、多选状态、备注计数、验证码分区和键盘高度适配；上游验证码token及校验不变。后端生成166×84PNG：灰度映射蓝白，彩图保留原色，等比留白不裁字；拒绝损坏/动画以避免丢信息，实际上游未在测试中调用。
- 默认按钮分隔线依用户截图删除；底部开始练习位置和其余布局保留。

验证：前端276项Node用例、全部官方WXML/WXSS编译通过；布局源码投影覆盖320/375/430宽和模拟短屏键盘，共33组弹层。模拟值仅为布局示例，不代表真实用户进度。后端212项Java测试、Mock微信/验证码HTTP、H2/隔离Redis均通过，无SQL迁移。最终验证码类另在生产同款Linux Java8基础镜像离线烟测通过，无网络/真实token。

真机键盘、音频、视频与实际上游验证码外观尚需真实使用验收；不把浏览器几何和源码测试写成全量真机通过。发布状态以release-2026-11-01.md为准。
