# iPhone纠错输入与练习卡片留白

用户iPhone实测上一版仍存在备注聚焦困难、验证码键盘弹起时过度上推后回落，并提供8.23秒录屏。本轮按录屏进一步修复，之前的浏览器检查不足以证明iPhone输入通过。

纠错弹层改为固定视口flex居中，键盘仅调整视口底部，不再在居中transform与顶部定位之间切换；入场只淡入，标题与按钮不随键盘切换样式。验证码input开启iOS同层渲染，两个输入都显式关闭系统自动推页并保留键盘，textarea继续声明fixed。正文使用原生scroll-view，聚焦备注时在键盘变化后的渲染回调滚动到备注；重复高度不再setData。内容自然高度用本组件selector测量，过期会话测量回调丢弃；短屏保留备注滚动可达空间。题目、账号、验证码token、提交互斥与遮罩规则不变。

练习顶部状态区从41px两行占位缩到22px单行，重试按钮同步22px并自动宽度，消除额外约19px底部留白；五种状态等高且同日进度静默刷新保留。

283项Node回归通过，含重复高度不重排、备注与数字键盘切换滚动目标、异步测量过期隔离。320/375/430宽的5种练习状态等高、无横向溢出；三组短屏/键盘高度下备注滚动后的首行、验证码点击命中均通过。微信官方WXML/WXS和WXSS编译通过。图像与录屏仅本地查看、未纳入上传包，未提交生产纠错或制造答题记录。

iPhone真实系统键盘尚无修复后的录屏或设备执行证据；本地源码、浏览器投影和开发者工具编译不能代替这部分验收。当前修复作为开发版更新，仍需用户真机复验。上传回执见release-2026-11-01.md。
