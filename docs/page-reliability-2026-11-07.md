# 页面交互与弱网体验优化

用户确认优化错题集、收藏返回、每日挑战与提醒加载，以及错题/百科币错误反馈，随后追加收藏页展示优化。

## 最终行为

- 错题答案按题目独立展开/收起。展开 A、B 再点击 A，只收起 A。
- 错题与百科币列表成功后才推进页码；连续触底不会重复请求。首屏失败显示持续可见的错误说明和重试入口，追加失败保留已加载记录并重试同一页。加载失败与真正为空分别展示。百科币明细支持下拉刷新。
- 页面刷新、隐藏、卸载或切号后，旧列表响应不写入新视图。会话在请求期间失效时显示登录入口。
- 错题删除会使服务器的偏移分页变化，因此完成删除后重新读取第一页。同账号删除在隐藏或刷新期间完成时，协调刷新当前视图或标记为返回后刷新；结果不确定时也重新核对服务器，不直接移除新列表的同一索引。
- 收藏未变化的普通返回保留已渲染列表及页码，避免重置原生浏览位置。账号切换、手动刷新、收藏版本变化及待完成写入仍触发读取；失败但可能已提交的写入同样使列表快照失效。离开期间中断的追加加载会释放加载提示，之后可继续同一页。
- 每日题目和提醒设置独立请求、独立状态与请求序号。提醒故障或缓慢不阻塞题目及答题按钮；提醒可在本区域重试。提醒状态未知时禁用修改，认证失效继续统一清空会话和旧数据。原生订阅仍在用户手势回调中立即发起，一次性订阅规则保留。

## 收藏页展示

收藏计数、题干、媒体和操作条重新分层；题干完整显示，媒体使用 200px 框等比展示。“去答题”使用品牌蓝强调。保留真实收藏时间与同一行的取消收藏、分享、去答题；取消收藏点击区为 44px，分享为 52px，不增加重复卡片标题。
