# 题目分享海报优化

范围为用户指定的「分享这道题」，延续项目已确认的蓝白方向。

- 蓝色品牌标题区、白色题目卡和底部扫码卡形成清晰层次，保留品牌名及“这道题，你会吗？”，加入品牌标语“知识无界，挑战不停”。
- 能容纳的短纯文字题使用 40px 加粗题干、132px 起的选项卡片，按实际内容高度居中排列。选项仍按 A/B、C/D 阅读，字母使用浅蓝底标识。
- 媒体与长内容保留原紧凑布局：题干图片仍在 360px 框内完整等比绘制，长题及长选项自然增高。题目卡延伸至内容或扫码区之前，避免短题留下分散的背景空白。
- 真实小程序码仍使用服务端完整图片绘入 300×300；绘码之前已恢复标题区裁切状态。版本限制、接口、身份验证、导出及保存流程保持原实现。
