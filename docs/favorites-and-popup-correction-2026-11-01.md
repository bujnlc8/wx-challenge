# 收藏与答错弹窗纠错

答错弹窗增加纠错和收藏入口，保留全屏点击屏障，不让背景穿透。纠错会保存当前复活/结束弹窗并打开独立纠错页，返回后恢复原选项；不触发扣币、复活、跳题、结束或重开。题目/轮次/账号/页面变化后丢弃旧弹窗。

题目底部保持纠错左、分享右，中间增加按账号收藏；错题列表使用紧凑星标；我的菜单新增无背景图标的收藏夹。收藏夹可取消、重新答当前一题，返回收藏夹；沿用现有单题首次答对1000币规则，不另建整轮挑战。

后端新增UID与题目联合主键收藏表，目标状态幂等设置、列表稳定分页。收藏和答题/金币/错题规则分离。前端同题两个实例共享已确认状态，未知状态只校准；防快速重复POST、跨账号旧响应、迟到列表读覆盖新写、取消后离开返回的分页偏移。

部署前在原授权服务器受保护目录完整备份challenge库，再执行可重复的question-favorite.sql；只新增收藏表，不回填或修改既有数据。保留旧容器可回滚。发布具体结果见release-2026-11-01.md。

验证：前端309项Node回归通过，官方21个WXML/WXS与22个WXSS编译及资源审计通过；后端固定Git归档独立221项测试与Java8 API构建通过。320/375/430宽的模拟微信默认按钮规则下，底部和弹窗收藏按钮宽度自然、无横向溢出。原生开发者工具截图尝试超时，未将其当作真机布局通过；界面示例未调用提交/收藏POST。


追加：收藏夹菜单使用与错题集一致的无背景数字，查询本人收藏列表size=1的真实total；0显示0，未知/失败为—。同账号保留旧值静默更新，换账号立即清理；等待本账号在途收藏写完成后再查，且隔离hide/unload/请求代次。新增7项计数回归验证这些边界。错题卡片的星标放在题干右侧，不占用原日期/分享/纠错行，长按星标不触发删除。


最终UI迭代：收藏页右上星标触发自定义取消确认，确认前无POST；关闭/保留不取消，重复确认只一次写。左下显示真实created_at且不做时区转换，右下保留去答题。首页恢复原宣传副文案，现有Logo/蓝色渐变品牌卡与合行榜单完成。最终326项前端回归通过，包含菜单7项、首页6项及收藏页新增确认/时间4项；后端独立221项及线上14项健康/鉴权检查通过。
