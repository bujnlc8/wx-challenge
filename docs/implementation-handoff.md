# 百科知识挑战交接

## 当前实现

- 12页均有具体导航标题；业务Toast、Loading、确认和选择弹窗均为自定义，微信授权与系统媒体控件仍由微信提供。
- 挑战、练习、单题使用分层题干、独立选项和固定底部主操作。纠错与海报分享随时可用，左右分列带图标；挑战计时继续，失败确认延迟到弹层关闭后显示。
- 练习顶栏为“模式 / 题号＋答对＋连对 / 用时”三个等距整体，中间用斜杠分隔；挑战保留模式、分数、计时与进度排列。上一题/下一题有可辨按钮底色、边框和按压反馈。
- 业务登录新版access有效2小时、refresh会话固定30天，提前刷新与明确401恢复均single-flight；原请求最多认证重试一次，网络未知错误不自动重放POST。同账号刷新保持页面所有权与每日订阅限额；退出清登录数据，保留偏好。
- 每日练习满100道不同题目送10000百科币，每天一次；错题计数、重复题不增数。真实SQL按用户、来源、北京时间当日去重，提交后清余额缓存。原练习上限与VIP规则保留。
- 单题答对1000分，并按每人每题一次真实奖励1000币；答错0分，完成后停留结果。独立于挑战轮次，无倒计时/复活/自动续题。正向计时在提交时停止，网络等待与重试不增用时。
- 普通挑战题数自定义1–100，默认10，下一轮生效，跳过计入。到数关闭本人轮次，未知结果可重试。
- 仅保留提示音效，移除BackgroundAudioManager及后台音频权限。业务按钮补齐点击反馈，选项与结果保留专用声音；关闭声音或隐藏App会停止并取消待播声音。
- 微信页面原生转发/朋友圈入口及分享奖励调用已移除，海报生成、预览、保存和图片分享保留。
- 题图固定200px完整等比展示，富文本内img同样固定框；视频框200px。题目海报主图360画布像素，视频为播放标志和扫码查看提示，不下载或截帧。普通短题/常见图题优先900×1200，长内容完整增高。
- 小程序海报严格900×1200，标语“知识无界，挑战不停”，蓝色品牌区与白色扫码区分层，真实Logo圆角、二维码完整。
- 练习Tab恢复举重人物元素；默认头像为眼镜探索者；数字盾牌等级压矮约21%，保持对称和数字清楚。
- “我的”题型长名称完整换行，选择面板使用原生scroll-view，标题和确认区固定；使用帮助为6条简短折叠问答。进入我的不弹登录提醒。
- 无用旧图已清理，Logo运行图512px并无损编码优化，原稿保存在不上传设计目录。设计、文档、测试、脚本、截图和本机私有配置等排除上传；COS SDK及动态等级图保留。
