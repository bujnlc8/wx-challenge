# 百科知识挑战交接

## 当前行为

- 共12个页面，包含新的独立单题页。三个Tab与答题页顶部间距统一8px。
- 普通挑战继续使用轮次、倒计时、跳过、复活、积分与奖励规则。分享指定题目和每日一题进入独立单题页：无轮次、倒计时、复活或自动续题；提交后显示本题结果和100/0分，不发挑战奖励币、不进入挑战榜。
- 单题答错进入有效错题集，单题记录不混入挑战累计统计；错题集入口使用有效记录，不被挑战累计错题数阻挡。
- 单题加载不产生答题记录。提交绑定所见题目版本；网络结果不确定时冻结答案和请求编号，重试恢复原结果。只有服务端明确确认未受理的题目版本冲突才可重新加载作答。
- “我的”为连续菜单列表，无分组、图标背景或数字胶囊。菜单名15px，右侧说明与数量13px，各组内部字重、颜色一致。百科币列入菜单；昵称下为数字盾牌等级与升级差额；退出位于关于页。
- 练习页保留与挑战一致的蓝色介绍卡，移除重复三项说明和底部宣传语，详细规则直接放在下方白卡。
- 使用帮助为独立页面；关于页保留Logo、名称、版本、海报分享与退出。
- Logo为无文字脑力答题图形。菜单图标为简洁单色线条，等级为可直接识别1–6的对称数字盾牌；空态带本地插图。
- 错题日期、分享、纠错位于同一底栏。纠错请求、验证码按弹窗会话、题目与账号隔离，旧响应不能关闭新弹窗，重复点击不会重复提交。
- 弹窗都有关闭按钮，内容自然撑开且受最大高度限制；完整透明点击屏障与页面滚动锁阻止穿透，长正文可内部滚动。Toast/Loading为自定义组件，操作句柄隔离并发请求。
- 题型选择使用确认后生效的自定义面板。页面进入、按钮和弹窗有轻量动效，并支持减少动态效果。

## 海报与每日挑战

- 关于页生成首页海报，题目可生成指定题目海报。两类Logo均圆角裁切，真实小程序码不裁切。通用海报900×1200；题目海报按内容增高以免截断。
- 保留旧二维码的答题页路径，通过重定向进入独立单题；无效或不可用题目明确报错，不退回随机题。海报生成支持真实PNG/JPEG码、预览、保存和失败重试。
- 小程序码按应用、路径、场景、运行版本和样式版本入库缓存，采用智能配色。已验证数据库原始图片及重启复用。
- 每日页展示今日共同题目与真实答题热力图；只累计追踪启用后的接受作答，不伪造历史。
- 北京时间08:00提醒使用一次性订阅。启用提醒后，有效答题提交每天最多自动请求一次，按账号、模板与北京时间日期在本机限制；拒绝、取消或失败当天不再自动弹。不同运行版本共用标记，凭据刷新不重置。
- 自动订阅不阻塞答题请求；普通挑战在原生授权面板结束后才进入下一题，不赠送额外答题时间。手动订阅可补充一次性机会。
- 每日页鉴权失效会清理登录数据和旧统计，保留偏好与每日订阅标记，并显示重新登录入口。旧账号晚到响应不能覆盖新账号。
