# 应用固定分享海报优化

**Goal:** 设计一张 900×1200 的固定应用海报，内置用户提供的小程序码，之后直接复用成品。

**Design:** 延续已确认的蓝白方向，使用真实圆角 Logo、大字“知识无界 / 挑战不停”、原副文案“用你的知识储备，刷新自己的纪录”，功能分区和独立白色扫码区。完整重排比仅调整字号更能改善品牌辨识与信息层次。

**Architecture:** `images/app-share-poster.png` 是最终运行资源。组件直接显示此路径，无后端请求及 Canvas 绘制；保存前通过 getImageInfo 读取本地图片路径，继续沿用相册权限反馈。所有环境使用同一张成品，不根据当前环境附加扫码成员限制。`design-demos/app-poster-render.js`、`app-poster-preview.html` 和用户码原图仅作为离线设计源，排除在运行包外。题目海报继续使用每题专属码动态绘制。

**Review Focus:** 无登录/未知环境仍可打开；重复打开不请求或绘制；读取失败可重试；保存过程关闭后无晚到副作用；完整保留 344×344 码像素。
