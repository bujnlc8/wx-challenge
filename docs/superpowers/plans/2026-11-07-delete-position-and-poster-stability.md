# 删除保位与静态海报首帧

用户要求错题删除成功后停留原地，不重载第一页；并反馈应用海报打开闪烁。

错题删除成功仅按记录 id 移除卡片，保留其他行、展开状态和页面位置。维护服务端已读偏移量，删除后回退偏移，下一次翻页允许重读边界页并按记录 id 去重，补齐缺口。使用删除标记过滤旧响应；同账号隐藏期间成功的删除返回时局部应用，切号/卸载不污染新视图。结果不确定时明确提示核实，保留当前列表，手动下拉仍可完整刷新。

应用静态海报一次发布完整可见状态，为固定 900×1200 图片预留 3:4 高度；保留入场动画及动态题目海报原流程。此部分由独立代理修改专属组件/测试文件，避免与错题修改冲突。
