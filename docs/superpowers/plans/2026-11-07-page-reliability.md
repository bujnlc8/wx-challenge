# 页面交互与弱网体验优化

**Goal:** 完成用户确认的四项优化：错题折叠及翻页、收藏返回保留位置、每日挑战/提醒独立加载、错题与百科币失败重试。

**Design:** 沿用蓝白页面样式。列表区分加载、成功为空、请求失败和已登录状态；首屏失败显示说明及重试，追加失败保留已有内容并重试同页。普通返回不刷新未变化的收藏列表，保留原列表及原生浏览位置。题目和提醒分别显示状态，提醒失败不阻塞答题，认证失效继续统一退出当前会话。

**Architecture:** 在当前四个页面中沿现有代码结构修改，不新增接口或依赖。所有异步结果受账号、页面生命周期和请求序号约束；页码只在成功后提交。收藏复用 `getFavoriteRevision` / `waitForFavoriteWrites` 决定是否刷新，账号切换、写入变更、手动下拉仍刷新。提醒使用独立状态及请求序号，关闭/切号/重新加载不会接受旧结果。

**Review Focus:** 第二页失败重试同页；连续触底只有一个请求；下拉后的旧响应无效；返回收藏不触发重置；提醒普通故障不影响答题而认证失效仍清空旧数据。

**追加展示范围:** 用户进一步要求优化收藏页展示。保留题干预览、完整媒体、真实收藏时间和同一行三项操作；梳理计数、题干和底部操作条层次，图片统一 200px 完整等比展示。取消收藏仍为 44px，分享仍为 52px，不增加卡片标题或改变操作逻辑。
