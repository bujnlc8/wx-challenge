# 独立题目纠错页

用户选择独立纠错页。目标是移除iPhone备注输入周围的固定定位、裁切及嵌套滚动，不继续修补弹窗键盘高度。

入口保持挑战、练习、单题、错题集现有按钮；保留题号、答案、计时、提交锁、1/2/4/16/8纠错多选、500字备注、六位验证码及原接口。纠错页普通文档流，textarea和input采用原生页面键盘避让，取消手动高度事件、fixed、transform、内部scroll-view及输入祖先overflow裁切。

备选：继续弹窗无法摆脱当前原生层约束；保留弹窗但备注跳页会割裂流程；用户已选独立完整表单页。

实现选择：原report组件只做空视图导航桥，维持四个答题页getCaptcha/nextQuestion入口契约；原会话安全及提交逻辑移入correction-form，由新correction页面承载。导航通过EventChannel仅传关闭状态；URL只传正整数question_id，无凭据。导航去重、失败清理、返回一次通知、旧题/旧账号隔离。错题集补全关闭状态回调。自然布局按钮随页面滚动，不添加新的浮动层。

只更新开发版。真实iPhone聚焦必须由修复后的真机使用验收，源码与编译不得冒充该证据。
